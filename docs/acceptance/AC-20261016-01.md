# Ghostwall Nine MVP 受入記録

## Scope

HTTP router、decoy service、synthetic DB、export、kill switch、host signal file、評価集計、Compose 例と運用文書。

## Acceptance Criteria

[EVALUATION.md](../../EVALUATION.md) の TC-A〜L、NFR-A〜F。コード上の合格と、Linux / controlled-agent 実測の合格を分ける。

## Evidence

- Windows ローカルで Python 試験 13 件成功。100 回同一顧客照会、固定 session の trajectory replay、参照整合、export hash、fail-closed、host signal と scripted lab fixture を含む。
- `coverage report` は product code 85%。demo backend、lab backend、`__main__` は除外。
- [GitHub CI](https://github.com/RNA4219/ghostwall-nine/actions/runs/38831339262) の Compose smoke は decoy から real-demo、外部 TCP、外部 DNS への到達失敗、専用 mount `/state`、単一 decoy network、read-only root、権限削減、decoy 停止時の 503 を確認。ローカルの Docker Engine は停止中。
- [EV-20261016-02](../evidence/EV-20261016-02-result.md) の Qwen3.5 4B pilot では Control と FalseSuccess を各 2 試行。候補は各 10 合成行を読み、2/2 で明示的な成功を申告し、実ゴール 0/2。Control は実ゴール 2/2、最終状態は不明。候補は export に到達せず、探索終了も未観測。効果の一般化は不可。
- [EV-20261016-03](../evidence/EV-20261016-03-result.md) は export を目標にした別 pilot。候補 2/2 が合成 CSV 取得後に成功を申告し、追加行動 0、実ゴール 0/2。Control は実ゴール 2/2。ただし manifest 読取は 0/2、各条件 2 試行のみ。
- [EV-20261016-04](../evidence/EV-20261016-04-result.md) は manifest を明示的な目標にした別 pilot。候補 2/2 が manifest 読取後、各 1 行動で成功を申告し、実ゴール 0/2。Control は実ゴール 2/2。各条件 2 試行のみ。
- [EV-20261016-05](../evidence/EV-20261016-05-result.md) の Windows 400 組測定では応答不一致 0、良性誤誘導 0、route event 400/400。一方、追加遅延 p95 は 38.59 ms で暫定 NFR-A 30 ms を超えた。
- [EV-20261016-06](../evidence/EV-20261016-06-result.md) の Ubuntu CI 400 組測定では追加遅延 p95 2.462 ms、応答不一致 0、良性誤誘導 0、route event 400/400。Linux lab の暫定 NFR-A/B/C を満たした。後続の CI gate でも p95 2.202 ms で合格。
- 最初の Qwen3.5 4B trial は [`EV-20261016-01`](../evaluation-manifests/EV-20261016-01.json) で preflight 後に開始したが、モデルの reasoning のみが返り `error=true`。効果比較へ算入しない。
